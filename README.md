# Explore. Evolve. Empower.

Build a production-quality responsive website called "WanderFitWealth".

WanderFitWealth is a modern lifestyle and personal-growth brand built around three pillars:

1. WANDER — travel, nature, adventure and eco-tourism

2. FIT — fitness, gym, boxing, MMA, yoga and healthy lifestyle

3. WEALTH — financial literacy, money management, entrepreneurship and career growth

Brand tagline:

"Explore. Evolve. Empower."

TARGET AUDIENCE

Young people, students, young professionals, fitness enthusiasts, travelers, aspiring entrepreneurs and people interested in improving their lifestyle and financial knowledge.

IMPORTANT DESIGN DIRECTION

Do NOT make this look like a generic AI-generated template.

Create a premium, modern, editorial-style website with strong visual hierarchy.

Design should feel:

- modern

- adventurous

- ambitious

- trustworthy

- youthful

- premium

- minimal but visually rich

Use a clean typography system, generous spacing, subtle animations, high-quality imagery and strong section transitions.

Avoid:

- excessive gradients

- excessive glassmorphism

- cheesy motivational quotes

- excessive animations

- cluttered layouts

- generic stock-business website styling

COLOR SYSTEM

Use a sophisticated natural palette:

- deep forest green

- off-white/cream

- charcoal/black

- muted earthy accent colors

The website should remain accessible with strong contrast.

SITE STRUCTURE

Create these pages:

1. HOME

2. WANDER

3. FIT

4. WEALTH

5. ABOUT

6. BLOG

7. CONTACT

HOME PAGE

Create a powerful hero section.

Headline:

"Explore. Evolve. Empower."

Supporting text:

"Travel farther. Build a stronger body. Build a smarter financial future."

Primary CTA:

"Explore WanderFitWealth"

Secondary CTA:

"Start Your Journey"

Hero visual should combine subtle elements representing:

travel/adventure + fitness + financial growth.

Then create a section introducing the three pillars:

WANDER

"Discover places worth remembering."

FIT

"Build strength, discipline and confidence."

WEALTH

"Learn how to manage, grow and build wealth."

Each pillar should have:

- large visual

- short description

- CTA

- hover interaction

Then add:

FEATURED JOURNEYS

Show travel destinations and experiences.

For the initial version, use example destinations such as:

- Deomali

- Koraput

- Daringbadi

- Satkosia

Clearly structure this so destinations can later be managed dynamically.

FITNESS SECTION

Show:

- Gym

- Boxing

- MMA

- Yoga

- Strength training

- Nutrition

Include a CTA:

"Build Your Stronger Self"

WEALTH SECTION

Cover:

- Personal finance

- Saving

- Investing education

- Career development

- Entrepreneurship

Important:

Do not provide financial advice that implies guaranteed returns.

Present financial content as educational information.

BLOG / STORIES

Create a modern content grid with categories:

Travel

Fitness

Money

Career

Lifestyle

Each article card should contain:

- image

- category

- title

- short excerpt

- date

- read more button

ABOUT SECTION

Explain the philosophy behind WanderFitWealth.

The brand should communicate that personal growth isn't just about money or fitness; it is about building a complete life through exploration, physical discipline and financial intelligence.

CONTACT PAGE

Create a clean contact form:

- Name

- Email

- Subject

- Message

Include social-media links placeholders.

NAVIGATION

Desktop:

Logo | Wander | Fit | Wealth | Blog | About | Contact

Mobile:

Use a clean hamburger menu.

Make the navbar sticky while scrolling.

FUNCTIONAL REQUIREMENTS

The website must be:

- fully responsive

- mobile-first

- fast-loading

- SEO-friendly

- accessible

- semantic HTML

- optimized for modern browsers

Add:

- smooth scrolling

- subtle page transitions

- hover effects

- scroll reveal animations

- responsive navigation

- loading states

- proper form validation

- 404 page

TECHNICAL REQUIREMENTS

Use:

- React

- TypeScript

- Tailwind CSS

- modern component architecture

- reusable components

- clean folder structure

Do not hard-code repeated UI.

Create reusable components for:

- Navbar

- Footer

- Hero

- Pillar cards

- Destination cards

- Blog cards

- CTA sections

- Buttons

- Forms

SEO

Add:

- proper page titles

- meta descriptions

- Open Graph metadata

- semantic headings

- image alt text

- sitemap-ready structure

- robots.txt

- clean URLs

PERFORMANCE

Optimize images.

Use lazy loading where appropriate.

Avoid unnecessary JavaScript.

Keep animations lightweight.

CMS / CONTENT ARCHITECTURE

Structure the project so that later I can connect a CMS or database for:

- destinations

- blog posts

- fitness programs

- financial articles

- newsletter subscribers

For now, use realistic sample content and placeholder images.

IMPORTANT BRANDING RULE

Do not make WanderFitWealth look like three unrelated websites.

The three pillars must feel like parts of ONE strong lifestyle brand.

The website should tell a story:

DISCOVER → BUILD → GROW

Wander = DISCOVER

Fit = BUILD

Wealth = GROW

FINAL GOAL

The finished website should look like a real startup/lifestyle brand website that could be launched publicly, not a student-project landing page.

Before finishing, check:

- mobile responsiveness

- desktop responsiveness

- navigation

- buttons

- forms

- broken links

- accessibility

- SEO metadata

- visual consistency

- spacing

- typography

- performance

Make the UI polished enough that I could deploy it as the official WanderFitWealth website.
